## Features
- Create Templates to use in Unity
- Create Unity Projects using 1 or more Templates
- Integrated Code preview
- Data bank for all your Projects
- System Auto-Update

## Tech Stack
Main Framework:Avalonia
DB+ORM: SQLite, EF Core
Tests: xUnit
Setup+AutoUpdate: VeloPack
CI/CD:GitHub Actions
